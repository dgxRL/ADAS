_mgsm/search.py — Agent Architecture Search on MGSM

ADAS (Automated Design of Agentic Systems) over multilingual grade-school math. The search loop writes Python agent code, runs it, and keeps what scores best — all LLM calls go to the local server http://mydgx0:8888/v1 (model GLM-5.3-Flash, JSON mode).

How evaluation works — evaluate_forward_fn

StepCodeDetail
1. Load agentexec(code)Generated forward() is exec'd and bound to AgentSystem.forward. Namespace must contain exactly one callable.
2. Build task setget_all_examples()MGSM problems, English + Chinese; shuffled with shuffle_seed=0; search mode takes valid_size=128 questions × n_repeat.
3. Run agentsThreadPoolExecutorOne task per question (max 4 workers). Inside forward(), the generated code spins up any number of LLMAgentBase agents (CoT, debate, critic…), each a JSON-mode chat call to the local LLM with exponential backoff on rate limits.
4. Scorescore_mgsmPredicted answer vs target per question → 0/1 acc_list.
5. Fitnessbootstrap_confidence_interval100k bootstrap samples → median + 95% CI string, stored as fitness.

Validation accuracy < 0.01 is treated as a failure and triggers a debug round, same as a raised exception.

End-to-end phases (main)

PhaseFunctionWhat happens
Seedget_init_archive()7 hand-written architectures: Chain-of-Thought, CoT Self-Consistency, Self-Refine/Reflexion, LLM Debate, Take-a-Step-Back, Quality-Diversity, Role Assignment. Each = {thought, name, code}.
Searchsearch(args)Scores any un-scored seeds, then loops n_generation=30 times: meta-prompt over the whole archive → new architecture → 2 reflexion passes → evaluate (≤3 debug rounds) → append & checkpoint. A generation that produces nothing usable is retried (n -= 1).
Testevaluate(args)Re-runs every archived forward() on the held-out test slice (valid_size : valid_size+test_size) and writes *_run_archive_evaluate.json with test_fitness. Resume-safe: skips already-evaluated entries.
